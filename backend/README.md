# Backend — AlugueMe

## Projetos

| Projeto | Função |
|---------|--------|
| `src/AlugueMe.Domain` | Entidades e enums |
| `src/AlugueMe.Application` | Casos de uso (Visits, WhatsApp, Properties…) |
| `src/AlugueMe.Infrastructure` | EF Core, Redis, Evolution, storage, workers |
| `src/AlugueMe.Api` | HTTP, OpenAPI, webhooks |

Solution e `.csproj` serão criados na Fase 0 (`dotnet new`).
